# CuidoMisPies — tema Shopify

Tema Shopify Online Store 2.0 convertido desde el prototipo original.

- La rama `main` conserva el proyecto anterior.
- La rama `shopify-mvp` contiene el tema listo para conectar con Shopify.
- La configuración completa está en `docs/CONFIGURACION_SHOPIFY.md`.

Validación:

```powershell
npx --yes @shopify/cli@latest theme check --path .
```
